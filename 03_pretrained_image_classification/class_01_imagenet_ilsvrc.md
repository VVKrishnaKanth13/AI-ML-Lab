# Class 1 — ImageNet and ILSVRC

## 1. What is ImageNet?

ImageNet is a large visual database designed for visual object recognition
research.

The goal of ImageNet is to provide a large collection of images that can be
used to develop and evaluate computer vision algorithms.

The ImageNet project was presented publicly in 2009.

---

## 2. ImageNet and Visual Recognition

ImageNet is used for computer vision tasks such as:

- Image Classification
- Object Recognition
- Object Localization

The dataset contains images belonging to many different object categories.

This makes ImageNet much larger and more challenging than datasets such as
Fashion-MNIST.

### Fashion-MNIST vs ImageNet

Fashion-MNIST:

- 10 classes
- Clothing-related categories
- Relatively simple image classification problem

ImageNet-1K:

- 1,000 classes
- Large variety of objects
- Much more complex visual recognition problem

---

## 3. What is ILSVRC?

ILSVRC stands for:

**ImageNet Large Scale Visual Recognition Challenge**

Starting in 2010, the ImageNet project ran an annual competition where
research teams evaluated computer vision algorithms on large-scale visual
recognition tasks.

Important tasks included:

- Image Classification
- Object Localization

---

## 4. ImageNet-1K

The ImageNet classification dataset used in the ILSVRC setting is commonly
referred to as:

**ImageNet-1K**

The "1K" refers to approximately:

**1,000 classes**

The training data contains approximately:

**1.2 million images**
